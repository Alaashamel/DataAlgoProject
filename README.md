# Telco Customer Churn Analytics Dashboard

An interactive Streamlit dashboard for analyzing customer churn in a telecommunications company.

## Features

- **Executive Overview**: Key business metrics and quick insights
- **Data Explorer**: Comprehensive data profiling and statistics
- **Data Processing**: Automated preprocessing pipeline with encoding
- **Interactive Visualizations**: Correlation analysis, churn analysis, and feature distributions
- **Churn Insights**: Actionable recommendations and financial impact analysis
- **Model Ready Data**: Machine learning preparation with train/test splitting

## Dataset

Uses the Telco Customer Churn dataset from Kaggle/WA_Fn-UseC_-Telco-Customer-Churn.csv

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run dashboard.py`

## Deployment

Deploy on Streamlit Cloud by connecting this GitHub repository.

## Technologies

- Streamlit
- Pandas
- Plotly
- Scikit-learn
